# Infinite Runner

A complete pseudo-3D endless running game built with Flutter. 

## Features
- **Endless Gameplay**: Procedurally generated paths that get progressively faster and more difficult.
- **Controls**: Swipe left/right to change lanes, swipe up to jump, swipe down to slide.
- **10 Unique Environments**: City, Village, Jungle, Desert, Snowy Mountains, Beach, Highway, Night City, Ancient Ruins, and Futuristic City.
- **Dynamic Elements**: Weather effects, day/night cycles, moving obstacles, and varied background scenery.
- **Power-ups**: Collect coins, magnets, shields, speed boosts, and coin multipliers.
- **Score Tracking**: High-score, distance, and coin counters.

## Getting Started

1. Ensure you have Flutter installed.
2. Run `flutter pub get` to install any dependencies.
3. Start the game on your preferred platform using `flutter run`.

## Tech Stack
- Flutter framework
- Custom pseudo-3D rendering using `CustomPainter`
